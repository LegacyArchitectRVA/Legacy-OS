# AI Core

LegacyOS agent framework.

## Agents

### Business Brain
Maintains company knowledge, SOPs, templates, and operational memory.

Capabilities:
- Document retrieval
- Knowledge search
- SOP assistance
- Business memory

### Executive Advisor
Challenges decisions, identifies risks, and pressure-tests assumptions.

Capabilities:
- Decision reviews
- Risk analysis
- Strategic evaluation

### Production Assistant
Maintains content systems, workflows, and brand consistency.

Capabilities:
- Content organization
- Brand guidelines
- Publishing workflows

## Powered by

- OpenAI models
- Retrieval augmented generation
- Embeddings
- Supabase vector storage (planned)
