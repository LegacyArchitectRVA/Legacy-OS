# LegacyOS Retrieval Pipeline

## Purpose

The retrieval layer connects business knowledge to the AI assistant while keeping each workspace isolated.

## Flow

1. User asks a business question
2. Query is scoped to workspace
3. Relevant knowledge chunks are retrieved
4. Context is assembled
5. AI response is generated using operational memory

## Future Enhancements

- Vector database integration
- Semantic ranking
- Confidence scoring
- Source citations
- Memory updates from approved decisions
