# LegacyOS Product Architecture

## Core Experience

LegacyOS acts as an operational memory system for individuals and organizations.

## Agents

- Business Brain: understands systems, SOPs, and repeatable processes.
- Executive Advisor: analyzes risks and opportunities.
- Production Assistant: helps execute workflows.
- Legacy Concierge: guides continuity preparation.

## Data Flow

Knowledge -> Processing -> Retrieval -> Agent Context -> Action

## Future Modules

- Automated reports
- Workflow automation
- Client portals
- Readiness assessments
