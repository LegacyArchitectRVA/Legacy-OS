# LegacyOS AI Assistant Core

## Purpose

The assistant layer connects the Business Brain, retrieval system, and workspace context into an operational advisor.

## Responsibilities

- Apply workspace-specific context
- Use retrieved business knowledge
- Identify missing information
- Provide operational recommendations
- Preserve business continuity thinking

## Response Flow

1. Receive user question
2. Load workspace identity
3. Retrieve relevant knowledge
4. Build AI context
5. Generate response
6. Log decisions when appropriate

## Future Enhancements

- Decision history
- Confidence scoring
- Automated recommendations
- Workflow execution
