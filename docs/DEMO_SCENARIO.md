# LegacyOS Demo Scenario

## Scenario

A business owner needs to preserve operational knowledge before an unexpected absence.

## Flow

1. Create workspace
2. Add company information
3. Upload SOPs and important documents
4. LegacyOS processes knowledge
5. User asks operational questions
6. Assistant provides context-aware responses
7. Continuity engine identifies gaps
8. System recommends actions

## Success Criteria

The user can understand what information exists, what is missing, and what should happen next.
