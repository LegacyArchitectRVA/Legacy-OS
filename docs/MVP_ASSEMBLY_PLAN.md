# LegacyOS MVP Assembly Plan

## Goal
Connect the existing architecture into a working operational AI experience.

## Assembly Order

1. Data Layer
- Connect workspace records
- Load knowledge documents
- Store operational context

2. User Layer
- Authentication
- Workspace onboarding
- Dashboard data loading

3. Intelligence Layer
- Retrieval execution
- AI context injection
- Recommendation generation

4. Continuity Layer
- Readiness scoring
- Risk detection
- Action planning

## First Demo Scenario

A business owner uploads operating documents, LegacyOS organizes the information, then answers questions using the company's own knowledge base.
