# LegacyOS Storage Architecture

## Storage Flow

User documents -> Cloudflare R2 -> Processing pipeline -> Knowledge database -> AI retrieval layer

## Storage Principles

- Business data remains isolated by organization
- Original files are preserved
- Processed knowledge maintains version history
- AI retrieval only uses approved organizational data

## Supported Future Files

- SOPs
- Policies
- Templates
- Contracts
- Training materials
- Business continuity documents
