# Legacy Recall

## Product thesis

**Recall what matters.**

Legacy Recall is the human memory layer of LegacyOS: an evidence-grounded record of a person's stories, memories, and relationships, built to preserve meaningful human context while the person is alive and make it discoverable by authorized people later.

Legacy Recall doesn't bring a person back, and it never presents an AI answer as the actual person. It answers from preserved evidence, and when it has to fill a gap, it says so.

## How it works

A loved one asks a question about a memory. Legacy Recall looks at the evidence attached to that person's record, generates an answer grounded in it, and returns the answer alongside a disclosure and the specific pieces of evidence it drew from.

If there isn't enough evidence to answer well, Legacy Recall says so rather than guessing. It surfaces what it does have instead of inventing the rest.

## Memory integrity

Every answer distinguishes between:

- **Verified**: directly supported by preserved evidence (photos, recordings, documents, notes, messages).
- **Reconstructed**: pieced together from available evidence, disclosed as such.

Legacy Recall never fabricates an event and presents it as fact. When evidence is thin, it says what it doesn't know.

## What goes into a memory

With the person's own authorization, Legacy Recall can hold:

- Photographs and video
- Voice recordings
- Notes, journals, letters, and messages
- Documents
- Locations and dates
- Life Manual information already on file

Every memory keeps its source, timestamp, and verification state attached, so whoever asks about it later knows exactly what they're looking at.

## Where it lives

Legacy Recall runs inside the LegacyOS dashboard: evidence goes into the Evidence Vault, memories get preserved with their sources attached, and a person's loved ones can ask about a memory and get an answer with its evidence shown alongside it.

## Product positioning

Legacy Recall isn't a digital resurrection product, an avatar, or a chatbot standing in for someone. It's a human memory layer inside continuity infrastructure for life, family, and business: it preserves what matters, keeps track of what's confirmed versus reconstructed, and gives the people left holding the keys something real to work from.

**Recall what matters.**
